# Gradle Wrapper JAR Omitted

`gradle/wrapper/gradle-wrapper.jar` is intentionally not committed in this repository.

To generate the wrapper jar locally (requires a system Gradle install):

```bash
gradle wrapper
```

Or download the wrapper jar that matches `gradle/wrapper/gradle-wrapper.properties` (`gradle-9.6.1`).

The `gradlew` / `gradlew.bat` scripts and `gradle-wrapper.properties` are present in this repo.
